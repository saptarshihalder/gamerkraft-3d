# Public roadmap

This roadmap is a public planning guide, not a delivery guarantee. Feedback and contributions are welcome through GitHub issues and discussions.

## Phase 1 — Collaborative foundation

- [x] Modular editor/runtime boundaries and asset metadata.
- [x] Automated formatting, linting, module tests, browser smoke checks, package verification, dependency review, and artifact-only Pages deployment.
- [ ] Establish protected default-branch rules and required status checks in the GitHub repository settings.

## Phase 2 — Authoring and performance

- [ ] Hidden-face culling and greedy meshing for larger voxel scenes.
- [ ] Voxel DDA picking and improved selection feedback.
- [ ] Expanded scene templates, import/export validation, and accessible editor controls.

## Phase 3 — Gameplay systems

- [ ] Behavior scripting for blocks and entities.
- [ ] More reusable game-mode and objective components.
- [ ] Replay tooling and deterministic simulation diagnostics.

## Phase 4 — Portable backends

- [ ] Complete renderer abstraction validation with alternate backends.
- [ ] Expand network authority and replication from contracts to playable multiplayer experiments.
- [ ] Package desktop/native deployment experiments without changing scene formats.
